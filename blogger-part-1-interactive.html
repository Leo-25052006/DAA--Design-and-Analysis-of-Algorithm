1What is an Algorithm?

A finite, precise procedure for solving a problem, like a recipe. It must have all five traits:

Input
Zero or more values
Output
At least one result
Definiteness
Unambiguous steps
Finiteness
Always terminates
Effectiveness

2The Big-O Race

We count steps, not seconds, because stopwatch time depends on the machine. Drag the slider to change the input size n and watch how many steps each class needs (bars use a log scale so everything fits).

n =16

Loop rules: nested loops multiply, sequential loops add, a loop whose variable halves is log n.

for (i = 1; i <= n; i++)         // O(n)
    for (j = 1; j <= n; j++)     // n x n = O(n^2)
        work();
for (i = n; i > 0; i = i / 2)   // halves each time: O(log n)
    work();
O (Big-O)
The ceiling: f(n) ≤ c·g(n)
Ω (Omega)
The floor: f(n) ≥ c·g(n)
Θ (Theta)
The sandwich: c₁g(n) ≤ f(n) ≤ c₂g(n)

Space complexity counts instruction space, the environmental stack and data space. Fixed space is O(1) (iterative factorial); variable space grows with n (an array is O(n)). Input space + auxiliary space = total space.

A queue is the opposite (FIFO): enqueue at the rear, dequeue from the front, like a ticket line. Stacks power undo and recursion; queues power scheduling and breadth-first search.

5Sets, Union-Find and Dictionaries

Set
Distinct items; two sets are disjoint if they share none.
Union-Find
Tracks which group an element is in and merges groups fast. Kruskal's algorithm (Part 3) uses it.
Dictionary
Unique keys paired with values, like a phone book.
